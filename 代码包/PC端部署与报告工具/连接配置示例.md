# PC 连接配置示例

在组装后的运行目录执行：

```powershell
$env:K1_HOST = "k1.local"
$env:K1_USER = "biandu"
$env:K1_KEY = Join-Path $HOME ".ssh/id_k1_agent"
python scripts/pc/k1.py --host $env:K1_HOST run "uname -m"
python scripts/pc/deploy_room_review.py --host $env:K1_HOST
```

K1_HOST 用主机名或当前实际 IP。专用工具以自己的 --host 参数为准。
私钥由用户在本机管理，本示例不创建、不复制密钥，也不包含密码。
板端 camera.device、音频 target 与 gimbal.config 需按实际设备核对，见主程序 configs/room_review_k1.json。
