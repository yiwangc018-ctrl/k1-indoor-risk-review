# 开源组件与模型说明

日期：2026-11-08。项目自有源码使用仓库根目录 MIT LICENSE；第三方组件和模型遵循各自许可证，
不能把项目 MIT 自动套用到模型或厂商二进制。本代码包不分发模型权重、运行时压缩包和系统镜像。

## 当前组件

| 组件 | 用途 | 来源 / 许可核对 |
|---|---|---|
| Python 标准库 | CLI、文件、socket、Linux I2C、测试 | Python Software Foundation License，以所用解释器为准 |
| numpy | ASR 前端与图片处理 | [numpy](https://numpy.org/)，BSD-3-Clause |
| Pillow | 图像读写、旋转、报告内嵌图片 | [Pillow](https://python-pillow.github.io/)，HPND 系许可，保留发行包声明 |
| paramiko | PC SSH/SFTP | [Paramiko](https://www.paramiko.org/)，LGPL-2.1，以安装版本元数据为准 |
| llama.cpp 厂商分支 0.1.7 | 本地多模态服务 | [spacemit-com/llama.cpp](https://github.com/spacemit-com/llama.cpp)，上游 LICENSE 为 MIT；下载包内第三方声明需保留 |
| spacemit-ort 2.0.6 | 视觉 ONNX / ASR ONNX 推理 | [spacemit-com/onnxruntime](https://github.com/spacemit-com/onnxruntime)，仓库 LICENSE 为 MIT；厂商包附加组件以包内声明为准 |
| Qwen3.5-0.8B | 图像到风险关注程度初评 | [官方模型卡](https://huggingface.co/Qwen/Qwen3.5-0.8B)，卡片标注 Apache-2.0 |
| SenseVoiceSmall | 本地语音识别 | [官方模型卡](https://huggingface.co/FunAudioLLM/SenseVoiceSmall)，标注 other/model-license，指向 [FunASR MODEL_LICENSE](https://github.com/modelscope/FunASR/blob/main/MODEL_LICENSE)；不能视为 MIT 模型 |

本次核对了上游模型卡和 llama.cpp/ORT LICENSE；没有把所有厂商包的第三方声明逐份审完。
发布带权重或带运行时的发行包前，要核对实际下载内容及 SenseVoice 模型许可条款。
