# 主程序运行说明

源码需先按代码包 README 组装，再从 `dist/运行目录` 部署；不要在本模块源码目录直接跑主链路。
完整设计见 [K1主程序开发文档](../K1主程序开发文档.md)，调用关系与测试数量以本次验证记录为准。

硬件基线：K1 MUSE Pi Pro、Bianbu 2.3.5、riscv64、Python 3.12；现场板约 15–16GiB 内存。
USB 摄像头按配置 by-id 枚举，1080P MJPEG；USB 麦克风和播放设备按实际枚举核对。
需要 Linux I2C 权限，云台通道为 CH15/CH11，不能套用旧配置 CH0/CH1。

板端当前有效入口：

```bash
cd /home/biandu/rv/room_review
bash scripts/board/start_room_review.sh
# 或直接：
bash scripts/board/voice_gimbal30.sh
# 缺提示音资源/音箱时：
bash scripts/board/voice_gimbal30.sh --no-cue --wait-enter
```

先阅读配置、核对相机方向和云台姿态，再动硬件。模型/运行时和系统依赖不在源码 ZIP 内。
0.8B/224 为当前路径，风险等级没有真实标签集准确率验证。30秒是历史采集/返回段记录，
不是语音、冷启动、分析、报告全部完成的时间承诺。
