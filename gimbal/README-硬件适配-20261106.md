# 硬件适配说明（K1 + PCA9685 + TBS-K15 270°）

更新时间：2026-11-06

## 这份代码是什么

`西瓜代码/` 是二维云台控制包，包名建议为 `gimbal`。本次按实际硬件和 PCA9685 数据手册修正：

- K1 通过 **I2C-4** 控制 PCA9685（地址 `0x40`）
- PCA9685 **CH0 = pan**，**CH1 = tilt**
- 舵机：**TBS-K15，270°，500–2500µs，50Hz**
- 供电：PCA 逻辑 `VCC=3.3V`；舵机 `V+=6V`（TBS-K15 支持 5–8.4V）
- 不再假设 tilt 是 180° 舵机

## 本次修改的关键点

### 1. PCA9685 必须打开 AI 自动递增

原 `pca9685.py` 初始化时没有设置 `AI` 位，导致 `set_ticks()` 一次写 4 个字节时，PCA 只把最后一个字节写到同一个寄存器，PWM 通道一直是默认 full-on。

已改为：

```text
MODE1 = ALLCALL | AI = 0x21
sleep 时 = 0x31
wake/restart
set_ticks() 改为逐寄存器写，双保险
```

本地寄存器测试结果：

```text
MODE1=0xA1  MODE2=0x04  PRESCALE=121
CH0 = [0, 0, 51, 1]   # 1500µs
CH1 = [0, 0, 51, 1]
PCA_DRIVER_TEST_PASS
```

### 2. 配置改为 TBS-K15 270°

`config.json`：

```json
pan:  travel=270, zero=0,   min=2,   max=267
tilt: travel=270, zero=135, min=35,  max=235
```

说明：

- 270° 舵机 `1500µs = 135°`
- tilt 机械行程约 220°，所以软件限位先收到 35–235
- 没有接 MPU 时 `require_mpu=false`、`tilt_closed_loop=false`；接上 MPU 后再打开

## 接 K1

### 方案 A：PCA 和 MPU 分总线（推荐）

PCA 走 I2C-4：

```text
K1 Pin 1 3.3V → PCA VCC
K1 Pin 3 SDA  → PCA SDA
K1 Pin 5 SCL  → PCA SCL
K1 Pin 6 GND  → PCA GND
```

MPU 走 I2C-3：

```text
K1 Pin 17 3.3V → MPU VCC
K1 Pin 27 SDA  → MPU SDA
K1 Pin 28 SCL  → MPU SCL
K1 Pin 25 GND  → MPU GND
K1 Pin 29 GND  → MPU AD0
```

`config.json`：

```json
"i2c": {"bus": 4, "mpu_bus": 3}
```

这样每组引脚只插一根线，不需要分线器。

### 方案 B：共用 I2C-4

PCA 和 MPU 共用 Pin 1/3/5/6，需要用面包板或 1 分 2 线：

```text
K1 Pin1 3.3V → PCA VCC + MPU VCC
K1 Pin3 SDA  → PCA SDA + MPU SDA
K1 Pin5 SCL  → PCA SCL + MPU SCL
K1 Pin6 GND  → PCA GND + MPU GND + MPU AD0
```

外部 6V：

```text
外部 6V + → PCA 绿色端子 V+
外部 6V - → PCA 绿色端子 GND（与 K1 Pin6 共地）
```

PCA 输出：

```text
CH0: GND/V+/PWM → pan 舵机（白线接 PWM）
CH1: GND/V+/PWM → tilt 舵机（白线接 PWM）
OE：悬空或接 GND
```

## 部署到板子

```bash
mkdir -p /home/biandu/rv/gimbal
# 把 西瓜代码/ 下所有文件拷到 /home/biandu/rv/gimbal/
cd /home/biandu/rv
python3 -m gimbal selftest
python3 -m gimbal detect
python3 -m gimbal pose --pan 135 --tilt 0 --hold 1
```

`pan=135, tilt=0` 对应两个舵机 **1500µs 中位**。

小角度测试：

```bash
python3 -m gimbal pose --pan 120 --tilt 0 --hold 1
python3 -m gimbal pose --pan 150 --tilt 0 --hold 1
python3 -m gimbal pose --pan 135 --tilt 15 --hold 1
python3 -m gimbal pose --pan 135 --tilt -15 --hold 1
```

## 注意

- 不给舵机供电时，I2C 仍能检测到 `0x40`，但舵机不会动。
- TBS-K15 不支持位置反馈，不能读回实际角度。
- 先小角度，再跑 `presets`/`scan`；不要一上来 0/270。
- 如果 `detect` 报 MPU 缺失，是正常的；当前测试只用 PCA。
